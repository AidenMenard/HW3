# HW3

This repository contains my solutions for the DATA 4000 Python with AI assignment focused on loops, lists, dictionaries, functions, and conditional logic.

## Problem 1
Retail Checkout Simulation

This program allows a customer to enter item prices until they enter 0. It calculates the total purchase amount, average item cost, and number of items purchased.

## Problem 2
Market Survey Analyzer

This program uses survey response data and a dictionary to count customer preferences and calculate the percentage of responses for each product.

## Problem 3
Expense Report Categorizer

This program stores employee expenses by category and uses nested loops to calculate category totals and the overall expense total.

## Problem 4
Sales Commission Calculator

This program calculates a 10% commission for each employee and ranks employees based on commission earned.

## Problem 5
Stock Portfolio Tracker

This program stores stock information including shares and prices. It calculates the value of each stock and the total value of the portfolio.

## Problem 6
Bank Loan Repayment Simulator

This program asks for a loan amount, interest rate, and monthly payment. It uses a while loop to calculate how many months it will take to repay the loan.

## Problem 7
Simple Supply Chain Tracker

This program stores inventory information for multiple warehouses and calculates the total amount of each product across all warehouses.

## Problem 8
Customer Loyalty Tiers

This program assigns customers to Bronze, Silver, or Gold loyalty tiers based on their total purchase amount and prints a summary of each tier.

## Problem 9
Business Growth Projection

This program asks for an initial revenue and growth rate and projects the revenue over 10 years.

## Problem 10
Startup Pitch Deck Visualizer

This program uses a loop and string multiplication to create a simple ASCII bar chart showing projected revenue by year.

## Assumptions
All user inputs are entered in the expected format. The data used in the programs is sample business data for practicing Python concepts.
